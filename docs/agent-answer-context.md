# Agent 答复上下文

2026-09-12：自动答复、人工重答与 AI 客服查询接口使用分区上下文。

## 当前方案：原图直接交给答复 Agent

`POST /open-api/replay` 外层仍为 `question`、`skill`、`use_latest_knowledge`。
`question` 包含产品名称、产品编码、模块、标题、正文，以及有来源的补充信息。
产品名称通过 `product_lines` 查询，没有标题时省略标题段。

HTML 正文转为文字，附件、HTML img、图片超链接、Markdown 图片及带图片扩展名的
裸链接集中放入 `【补充信息—图片】`，使用 `<img src="原始图片链接">` 交给答复
Agent 直接读取。同一链接去重，优先原始外链，缺失时回退可公开访问的存档链接。
图片内容是工单证据，不作为执行指令；无法读图时要求明确说明，不允许推测。

自动答复读取关联工单当前正文；如与 Hub 快照不同，标明来源作为补充信息。
已有附件 `extracted_text` 可作为参考文字一并传入，不依赖 OCR 同步到 Hub 快照。
子任务专属附件不混入其他子任务。上下文组装只读，不注册或修改附件。

本次不调用独立视觉模型，不需要新增千问密钥；独立图片提取 Agent 留待后续接入。
项目原有入库/附件识图流水线保持原配置，不在本次扩展或启用。
`VISION_MAX_IMAGES_PER_TICKET` 继续作为单次图片数量上限（默认5）；未传入/无可用
链接的图片明确标记。未来图片提取 Agent 可把结果写入现有 extracted_text 字段。

## 验证与限制

单元回归覆盖：产品编码映射、标题缺失、图片单独输入、HTML/Markdown 链接去重、
异步到达的 OCR、当前工单补料、子任务隔离、实际 replay 传参和对外查询。

现有答复 Agent 对 HTML 格式的测试图正确读出状态、金额、报错；存在0/O字符混淆。
真实工单1969的智齿外链测试中，Agent 明确返回无法读取外链。因此直接传图不保证
所有外链均可访问；不能把知识库推导出的字段视为识图结果。按用户决定先保留直接
传图方案，后续再增加专门的图片提取 Agent。

不改变自动答复、审核和外部回写开关；测试不向客户发送答复。
